# Security Policy

FraudShield AI is an academic research prototype.

## Reporting Security Issues

Please do not publicly disclose security vulnerabilities through GitHub Issues.

Instead, contact the project maintainer privately.

## Sensitive Information

Contributors must never commit:

- passwords
- Neo4j credentials
- API keys
- banking credentials
- OTPs
- PINs
- private financial data

## Disclaimer

FraudShield AI is not intended for production banking or payment processing.
