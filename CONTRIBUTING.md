# Contributing to FraudShield AI

Thank you for your interest in contributing to FraudShield AI.

We welcome improvements in research, model development, backend systems, Android interfaces, graph analytics, testing, and documentation.

## How to Contribute

1. Fork the repository.
2. Create a new branch:

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes.
4. Test the project and validate the behavior.
5. Commit your changes:

```bash
git add .
git commit -m "Add: description of feature"
```

6. Push your branch:

```bash
git push origin feature/your-feature-name
```

7. Open a Pull Request.

## Contribution Areas

Contributions are welcome in the following areas:

- Fraud detection models
- Android UI improvements
- Behavioral telemetry
- Neo4j graph analytics
- Explainable AI
- Testing
- Documentation
- Privacy and security improvements

## Important

Please do not commit any of the following:

- Passwords
- API keys
- .env files
- Neo4j credentials
- Private financial information

FraudShield AI is currently an academic prototype and should not be represented as a production banking security system.
